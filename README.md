# Genesis

Sitio web y sistema interno de gestión (pacientes, historia clínica, agenda) para Genesis Estética Integral, Córdoba.

**Estado:** Fase 0 — demo con datos 100 % ficticios.

## Stack
Next.js 15, TypeScript, Tailwind, PostgreSQL 16 (Drizzle), Turborepo. Ver `docs/decisiones.md`.

## Estructura
`apps/web` (sitio público) · `apps/panel` (sistema interno) · `packages/{db,ui,config}` · `content/` · `docs/`
